# 07 · Montar o contexto

Responsabilidade: juntar a composição num **contexto único** que vai para a geração (`09`).
Na tela é o que aparece em **Copiar contexto** / **Ver contexto usado**.

## Formato (markdown)
```
# Contexto para micro conteúdo
## Destinatário          ← 01 (exatamente 1)
## Gancho (notícias/problemas)   ← 02
## Prova (métricas)      ← 03 (só as autorizadas viram texto)
## Visual (design)       ← 04
## Produto (telas e roteiro)     ← 05
## Momento (sinais de compra)    ← 06
## Canal                 ← E-mail ou WhatsApp
## Objetivo              ← primeiro contato · nutrição · convite para reunião · reativação
## Observações           ← texto livre do CSA
## Diretrizes            ← geradas pelas travas do 08
```

## Regras
- Slot vazio aparece como `(não selecionado)`: a geração não pode preencher esse buraco inventando.
- A seção **Diretrizes** é obrigatória quando alguma trava do `08` disparou.
